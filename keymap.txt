# RemoteMapper keymap config  (updated 2026-08-13)
# mapping-enabled: 1
# RemoteMic 启动时读取本文件；控制面板保存后立即热加载，无需重启。
# 驱动把可配置遥控器键变成 F13-F19，再由本文件决定目标快捷键；语音键另改为保留的 F20，由 VoiceKeyBlocker 直接吞掉，不进入本配置。
# 方向键和确定键保持系统原行为，不要写成组合键映射源。
#
# 完整 HID 映射 (Android getevent 抓取, 全部 Usage Page 0x0007 键盘页):
#   电源键   HID 0x066 -> 驱动改为 HID F19 -> VK 0x82 (VK_F19)
#   确定键   HID 0x028 -> VK 0x0D (VK_RETURN)
#   方向上   HID 0x052 -> VK 0x26 (VK_UP)
#   方向下   HID 0x051 -> VK 0x28 (VK_DOWN)
#   方向左   HID 0x050 -> VK 0x25 (VK_LEFT)
#   方向右   HID 0x04F -> VK 0x27 (VK_RIGHT)
#   返回键   HID 0x0F1 -> 驱动改为 HID F15 -> VK 0x7E (VK_F15)
#   主页键   HID 0x04A -> 驱动改为 HID F16 -> VK 0x7F (VK_F16)
#   音量加   HID 0x080 -> 驱动改为 HID F13 -> VK 0x7C (VK_F13)
#   音量减   HID 0x081 -> 驱动改为 HID F14 -> VK 0x7D (VK_F14)
#   菜单键   HID 0x065 -> 驱动改为 HID F17 -> VK 0x80 (VK_F17)
#   直播键   HID 0x035 -> 驱动改为 HID F18 -> VK 0x81 (VK_F18)
#   语音键   HID 0x03E(F5) -> 驱动改为 HID F20 -> VK 0x83 (VK_F20)
#            (RemoteMic 的 VoiceKeyBlocker 吞掉 F20，不放行到前台应用；
#             触发信号走 BLE CTL 通道。物理键盘 F5 不受影响。)
#
# 每行格式:
#   <键名> = <vk> -> <目标组合>
# 目标组合: 键名用 + 连接, 例  LALT+TAB   /   RALT+OEM_COMMA   /   LWIN+D
# TAP 前缀 = 源键抬起后原子点按目标组合，避免源 F 键与目标修饰键形成 Windows 保留组合。
# 手势语法 (用 | 分隔，可组合):
#   TAP <组合>            单击: 源键抬起后原子点按
#   DOUBLE <毫秒> -> <动作>  双击: 两次按下间隔 < 毫秒时触发，单击延迟到窗口结束
#   HOLD <毫秒> -> <动作>    长按: 按住达到毫秒后立即触发一次 (与 REPEAT 互斥)
#   REPEAT <延迟> <间隔> -> <动作>  连发: 延迟后开始，每隔间隔重复触发 (与 HOLD 互斥)
#   TASKVIEW = 通过 Explorer Shell 打开任务视图，不注入 Win 键。
#   LAUNCH <路径> [参数]   启动程序
#   CMD <命令>             交给 cmd.exe /c 执行
# 组合示例:
#   菜单键 = 0x80 -> TAP X | DOUBLE 300 -> TAP Y | HOLD 550 -> TAP Z
#   音量加 = 0x7C -> TAP BACK | REPEAT 350 100 -> TAP BACK
# -> 后面留空 = 不映射, 该键照常放行。
#
# 支持的目标键名:
#   A-Z  0-9  F1..F24  LSHIFT/RSHIFT  LCTRL/RCTRL  LALT/RALT  LWIN/RWIN
#   OEM_COMMA(,)  OEM_PERIOD(.)  OEM_PLUS(+)  OEM_MINUS(-)  OEM_1(;)  OEM_2(/)  OEM_3(`)
#   SPACE  ENTER  TAB  ESC  BACK  CAPSLOCK  INSERT  DELETE
#   HOME  END  PGUP  PGDN  LEFT  UP  RIGHT  DOWN  MENU  PRTSCR
# 特殊: ALT+TAB (任务切换, 注入会弹出切换器, 放开 Alt 时切换)
